옆메모 개인정보 처리방침

시행일: 2026년 9월 16일

핵심 안내
옆메모는 사용자의 메모 내용을 외부 서버로 전송하지 않으며, 광고·분석·회원가입 기능을 사용하지 않습니다.

1. 수집하는 개인정보

옆메모는 이름, 이메일 주소, 연락처, 위치 정보, 기기 식별자 등의 개인정보를 수집하지 않습니다.

2. 메모 데이터의 저장과 이용

사용자가 작성한 메모, 앱 설정 및 알람 정보는 사용자의 Windows 기기 내 앱 전용 저장공간에만 저장됩니다. 해당 데이터는 메모 작성, 표시, 알람 및 앱 설정 기능을 제공하는 용도로만 사용됩니다.

3. 외부 전송 및 제3자 제공

옆메모는 메모 데이터나 개인정보를 개발자 또는 제3자의 서버로 전송하거나 제공하지 않습니다. 광고 및 사용자 행동 분석 도구도 포함하지 않습니다.

4. 파일 가져오기와 내보내기

사용자가 직접 선택한 텍스트 파일을 가져오거나 메모를 파일로 내보낼 수 있습니다. 파일 읽기와 저장은 사용자의 명시적인 조작으로만 실행되며, 선택한 파일은 외부로 전송되지 않습니다.

5. 데이터 삭제

사용자는 앱에서 메모를 직접 삭제할 수 있습니다. 앱의 모든 로컬 데이터를 제거하려면 Windows에서 앱을 제거한 후 앱 데이터가 남아 있는 경우 해당 데이터를 삭제할 수 있습니다.

6. 아동의 개인정보

옆메모는 개인정보를 수집하지 않으며, 아동을 대상으로 개인정보를 요구하거나 수집하지 않습니다.

7. 처리방침 변경

앱 기능 또는 관련 법령이 변경되면 이 처리방침이 수정될 수 있습니다. 중요한 변경 사항이 있는 경우 이 페이지를 통해 변경 내용과 시행일을 안내합니다.
